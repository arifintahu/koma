# TUI /model

## TUI /model
Choose a role and switch its model. Use `/model help` for documentation.

The /model command switches the active model for a specific role or agent — right from the chat input. No need to navigate to settings.

Bare `/model` opens a picker for main, awareness, planner, compactor, and safeguard.
Use arrows and Enter, or click a role, to open its model list. Existing shortcuts
such as `/model main` and `/model planner` open that list directly.

Type or paste into the search field to filter by model name, model ID, or provider.
Arrows browse matches; Enter or clicking a result applies it. No matches leaves the
current binding intact. Esc returns to the role list when opened from bare `/model`,
or closes a picker opened directly. `/model help`, `/model ?`, and the agent commands
remain available.

Use /help for the registered command and keyboard reference. This is a TUI slash command; the GUI uses its corresponding controls.
