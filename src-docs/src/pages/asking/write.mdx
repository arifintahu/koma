# Write a request

The box at the bottom is a note to a colleague. Say what you want back, and what it must include.

import { Guide } from '../../components/Guide.client'
import { writeSteps } from '../../guides/asking'

<Guide steps={writeSteps} />

Enter sends the note. Shift+Enter, or Ctrl+J, adds a line without sending. Use a second line for constraints: the audience, the date, the file to use.

You do not prefix an ordinary request with a slash. A slash is only for the commands in the reference.

:::note[If this is not what you see]
If the box shows `[/]` you have started a command. Backspace until it shows `[$]` again, then type the request.
:::
