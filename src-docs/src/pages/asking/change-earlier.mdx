# Change an earlier request

Use this when a later turn went the wrong way and you want to rewrite from an earlier message.

import { Guide } from '../../components/Guide.client'
import { rewindSteps } from '../../guides/asking'

<Guide steps={rewindSteps} />

Press Esc, then Esc again. Choose the message. Edit it and send.

Koma sets aside the turns that came after that message, so the conversation continues from your rewrite.

:::note[If this is not what you see]
One Esc stops work in progress. Two Esc presses open the earlier-message list. If a menu is open, Esc closes that menu instead.
:::
