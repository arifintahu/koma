# While koma is working

After you press Enter, you do not have to do anything. The screen tells you it is still working.

import { Guide } from '../../components/Guide.client'
import { workingSteps } from '../../guides/asking'

<Guide steps={workingSteps} />

The bottom line shows a working word and a timer. A short note may show what koma is reading or changing. The answer, when it arrives, stays in the conversation.

Scroll with the up and down arrows, or with the mouse wheel, to reread an earlier turn.

Press Esc if you want it to stop.

:::note[If this is not what you see]
A notice that flashes and disappears is saved. Type `/notification` if you missed it.
:::
