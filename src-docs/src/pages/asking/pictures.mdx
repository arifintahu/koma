# Add a picture or a note

You can hand koma a picture or a long paste without dropping it all into the typing box.

import { Guide } from '../../components/Guide.client'
import { pictureSteps } from '../../guides/asking'

<Guide steps={pictureSteps} />

Copy a picture, click the terminal, and press Ctrl+V. Type what you want koma to do with it, then Enter.

A long paste becomes an attached note. Ctrl+P opens the pictures and notes waiting to send. Alt+E edits the nearest one. The small × on a chip removes it before you send.

:::note[If this is not what you see]
If Ctrl+V pastes text into the box instead of a picture, the clipboard did not hold an image. Copy the image again from the program that showed it.
:::
