# Send the same request again

When the answer missed the point, you can send the same request again without retyping it.

import { Guide } from '../../components/Guide.client'
import { againSteps } from '../../guides/asking'

<Guide steps={againSteps} />

Press Ctrl+R.

If you want a different result, say what was wrong instead of only repeating. “Make it half as long, and lead with the date” is a better follow-up.

:::note[If this is not what you see]
Ctrl+R repeats the last thing you sent. It does not repeat a command you only typed and then deleted.
:::
