# Find a conversation

Type `/resume` whenever you cannot see the conversation you want. You can also start from `koma agents`, which opens this list directly.

import { Guide } from '../../components/Guide.client'
import { findSteps } from '../../guides/conversations'

<Guide steps={findSteps} />

Cooking is what is open now, including work you detached. History is what you finished or closed.

Tab switches the two lists. Enter opens the row. On Cooking, Ctrl+X asks before it stops a conversation. On History, Ctrl+X asks before it deletes one.

:::note[If this is not what you see]
A brand-new install has an empty History. That is expected. Start a conversation, leave it, and it will show up here.
:::
