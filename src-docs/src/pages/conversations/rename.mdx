# Rename a conversation

A name makes the list useful. “quarterly brief” is easier to find than a random id.

import { Guide } from '../../components/Guide.client'
import { renameSteps } from '../../guides/conversations'

<Guide steps={renameSteps} />

Type `/rename` and the name, then Enter. The name moves onto the corner of the typing box and onto the row in Cooking and History.

:::note[If this is not what you see]
If the name does not change, check that you pressed Enter after the name, not only after `/rename`.
:::
