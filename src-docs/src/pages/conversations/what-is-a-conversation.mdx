# What a conversation is

A conversation is one thread of work. It remembers what you asked, which folder it is using, and how careful you asked koma to be.

import { Guide } from '../../components/Guide.client'
import { chatSteps } from '../../guides/start'

<Guide steps={chatSteps} />

The name on the typing box is the conversation’s name. Two conversations do not share a chat. They can run at the same time.

Start a new one when the subject changes. Stay in this one when you are still on the same piece of work.

:::note[If this is not what you see]
The word session is the same thing. This book says conversation.
:::
