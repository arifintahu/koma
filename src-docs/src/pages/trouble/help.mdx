# Help inside koma

You can open a short list of commands and keys from inside the conversation.

import { Guide } from '../../components/Guide.client'
import { helpSteps } from '../../guides/trouble'

<Guide steps={helpSteps} />

Type `/help`. Type to filter. Enter runs the command you are on. Esc closes the list.

This list is a reminder. The pages in this book explain when to use each one.

:::note[If this is not what you see]
If `/help` is not recognized, the box may not have sent it. Press Enter after the word.
:::
