# Copy the conversation

You can copy what is on screen with your terminal’s normal selection. There is also a command for the whole conversation.

import { Guide } from '../../components/Guide.client'
import { copySteps } from '../../guides/trouble'

<Guide steps={copySteps} />

Drag to select, then copy the way you usually do in this terminal.

Type `/select` when you want the full conversation printed so that same copy can take all of it. The chat you see is already selectable. `/select` is for the part that has scrolled out of a convenient selection.

:::note[If this is not what you see]
If drag-select fights the mouse wheel, set Mouse capture to Off in General settings, then try the drag again.
:::
