# The terminal cannot start

If koma tells you it cannot prepare the terminal, this computer could not start the new one. The usual cause is a machine that does not meet the requirement: macOS 13 or newer, a current Linux, or Windows 10 or newer.

You can still open the older terminal:

```sh
koma legacy
```

That older window is a fallback. This book describes the terminal you get from `koma` on its own. Use the older one only until this computer can start the new one.

:::note[If this is not what you see]
A normal `koma` launch that reaches the welcome screen or the chat does not need `koma legacy`.
:::
