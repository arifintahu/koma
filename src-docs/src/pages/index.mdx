# Koma

Koma is a helper that lives in the terminal. You tell it what you want done. It reads the folder, drafts the work, and can change files and run commands when you let it.

[koma.run](https://koma.run) is the home for the product.

You do not need to have used koma before. Start with the first launch, then come back to any page when you need it.
