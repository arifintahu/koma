# The free connection

The free connection needs no account. You can use it for one conversation even if the others use a paid model.

import { Guide } from '../../components/Guide.client'
import { freeSteps } from '../../guides/careful'

<Guide steps={freeSteps} />

Type `/free`. This conversation switches to the free models koma hosts. Type `/free` again to return to the model you configured.

This does not change your saved account. It only changes this conversation.

:::note[If this is not what you see]
If you have never connected anything, the welcome screen’s koma free choice is the same connection, set up from the start.
:::
