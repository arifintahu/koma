# Keys

These are the keys koma lists, plus the ones the tip line mentions. Click the terminal so the key goes to koma.

| Key | What it does |
| --- | --- |
| Enter | Send what you typed, or run the command. |
| Tab | Complete the command or file that is highlighted. |
| Shift+Tab | Cycle Auto, Normal, Planning, and SDLC. |
| Shift+Enter | Start a new line without sending. |
| Ctrl+J | Start a new line without sending. Same as Shift+Enter. |
| Ctrl+R | Send the last request again. |
| Ctrl+E | Switch internet between simple and full. |
| Ctrl+V | Paste a picture from the clipboard. |
| Ctrl+P | Open pictures and notes waiting to be sent. |
| Alt+E | Edit the nearest attached note or picture. |
| Ctrl+B | Let a blocking helper or command keep going in the background. |
| Ctrl+X | Stop the command or helper you have selected. On the conversation list, stop or delete the row, after you confirm. |
| Esc | Stop the request that is running. Also closes a menu. |
| Esc Esc | Open the list of earlier messages so you can rewrite one. |
| Up/Down/wheel | Scroll the conversation. |
| Ctrl+C | Ask before quitting. |
| @ | Start naming a file in the folder. |

:::note[If this is not what you see]
A key does nothing when another program, or the terminal app itself, takes it first. Click the koma window and try the key again.
:::
