# How to use an extension

An extension adds something Koma can do: a tool, a tab, a terminal screen, or a sign-in. You use one from inside Koma. You do not paste it into the chat.

This protocol is still version 0. It will change.

## Use one that is already on this computer

Open Koma. Type this and press Enter.

```text
/extension
```

<Guide steps={installedSteps} />

That list is installed software. It is not on for this conversation yet.

Type this and press Enter.

```text
/extension use
```

<Guide steps={useSteps} />

Highlight the row and press Enter. That add-on can now be called in this conversation. Other conversations stay as they were. Press Esc to go back to the chat.

Then ask in a normal sentence. For the echo sample, the tool is named echo and it takes the text you want repeated.

```text
Use the echo tool. The text is hello.
```

Koma calls the extension, the extension answers, and you see the reply in the chat.

## Use one from the store

Type this when you want an add-on Koma publishes, instead of one you built.

```text
/store
```

<Guide steps={storeSteps} />

Enter opens the row. Install asks before it downloads. After it is installed, go back and run /extension use so this conversation can call it.

## Try the echo sample yourself

This is the shortest extension. It adds one tool and does not call back into Koma. From the src-extension directory:

```sh
cargo run -p echo-tool-daemon
```

No Koma window is required for that command. The program prints the handshake and a pretend tool call whose text is hello. Read that printout. It is the same call Koma will make after you install the extension.

When the printout looks right, pack it and install it on this machine.

```sh
./pack.sh
koma ext install --dev dist/echo-tool-daemon.zip
```

Open Koma, run /extension, then /extension use, and choose Echo Tool. Ask it to echo hello, as above.

The manifest, grants, and the other samples are the reference for when you write your own. You do not need them to use one. [Smallest program](/extension/first) is the next page if you want to change the echo tool.
