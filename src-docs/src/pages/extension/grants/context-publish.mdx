# context:publish


Set replaces this extension entry in the system prompt. Empty or whitespace text clears the entry and still returns ok. The cap is 8KB for this extension.

```json
{ "method": "context.set", "params": { "text": "The client prefers short sentences." } }
```

```json
{ "ok": true }
```

Clear takes no fields. Clearing when nothing was set still succeeds.

```json
{ "method": "context.clear", "params": {} }
```

The text is appended after the cached prefix, keyed by your extension id. One entry per extension. Publishing does not break the cached head of the prompt. Over the cap, the error is: context exceeds 8KB.
