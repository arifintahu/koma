# models:invoke


One verb. prompt is required and non-empty. role defaults to main. system and format are optional. role is one of main, awareness, safeguard, compactor, or planner.

```json
{
  "method": "models.invoke",
  "params": {
    "prompt": "List three risks in this brief.",
    "role": "planner",
    "system": "Answer in short sentences.",
    "format": "json"
  }
}
```

Success is output and the model id.

```json
{ "output": "{ \"risks\": [] }", "model": "gpt-4.1" }
```

prompt over 32KB is rejected. An unknown role is: unknown role. It does not fall back to main. A missing route, a route that cannot be called, missing auth, and a missing client are each a distinct error.

The inner budget is 330 seconds. The wire budget for this verb is 360 seconds, so a stuck call still returns: model call timed out. Other verbs use a 120 second wire timeout.

format json asks for a JSON object on OpenAI-compatible chat routes. On Codex and Anthropic-compatible routes the field is ignored, not rejected. Any other value, or a missing field, is ordinary text.
