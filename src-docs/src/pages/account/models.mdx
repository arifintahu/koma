# Models

This page is the same choice as `/model`, shown as a list.

import { Guide } from '../../components/Guide.client'
import { modelsPageSteps } from '../../guides/account'

<Guide steps={modelsPageSteps} />

Press 4 inside settings. Each row is a job: the model that answers you, and the helpers that read the project, check safety, shorten a long conversation, and draft a plan.

Enter changes the row. The conversation uses the new model on the next request.

:::note[If this is not what you see]
If a model you expected is missing, the provider for that model is not connected. Add the provider first.
:::
