# Themes

The theme is only color. It does not change what koma can do.

import { Guide } from '../../components/Guide.client'
import { themeSteps } from '../../guides/account'

<Guide steps={themeSteps} />

Open `/settings`, move to Appearance, and press Enter on a theme.

The themes are dark, light, forest, autumn, warm, cold symphony, winter, monokai, vscode, and github dark.

The choice is remembered the next time you open koma.

:::note[If this is not what you see]
If the color does not change, press Enter on the row. Highlighting a row is not the same as applying it.
:::
