# A tour of settings

Settings is where the connection, the look, and the everyday switches live. You can open it from any conversation.

import { Guide } from '../../components/Guide.client'
import { settingsSteps } from '../../guides/account'

<Guide steps={settingsSteps} />

Type `/settings`. `/config` opens the same place.

The first page is quick: theme on one side, general switches on the other. Press 2 for providers, 3 for sign-in, and 4 for models. Esc returns to the chat.

:::note[If this is not what you see]
If the numbers do nothing, click the terminal and try again. The numbers switch pages only while settings is open.
:::
