# Sign-in connections

Sign-in is for accounts that use the browser, rather than a key you paste.

import { Guide } from '../../components/Guide.client'
import { oauthSteps } from '../../guides/account'

<Guide steps={oauthSteps} />

Press 3 inside settings. Enter on a row starts the sign-in, or reconnects an account that expired. Finish in the browser, then return to the terminal.

:::note[If this is not what you see]
A row that says it is not connected is unused. You can leave it. Connect it only when you want that account.
:::
