# Sign in to an account

Choose Connect a provider on the welcome screen when you already pay for an account, such as ChatGPT or Claude.

import { Guide } from '../../components/Guide.client'
import { signInSteps } from '../../guides/start'

<Guide steps={signInSteps} />

Koma opens your browser for the sign-in. The password stays on that website. When the site says you are signed in, return to the terminal and pick a model.

That model is the one that answers in this conversation. You can pick a different one later.

:::note[If this is not what you see]
If the browser does not open, copy the address koma prints and paste it into the browser yourself. If the account is not in the list, use your own key instead.
:::
