# What koma does for you

Koma sits in a terminal window and works on the folder you opened. You write in ordinary language. Koma reads, drafts, and can change the work when you allow it.

This book is about that window. It is not about a website, and it is not about writing code by hand.

A conversation is one piece of work. You can have several at once. Closing the window does not throw the work away.

When you are ready, install koma and open it once. The next pages walk that first launch.

:::note[If this is not what you see]
If you opened a desktop window instead of a terminal, you are in a different koma. This book follows the terminal you get by running koma.
:::
