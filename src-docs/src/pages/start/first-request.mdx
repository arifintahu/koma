# Send your first request

Click the box at the bottom and type what you want. You do not need a slash command for ordinary work.

import { Guide } from '../../components/Guide.client'
import { firstRequestSteps } from '../../guides/start'

<Guide steps={firstRequestSteps} />

A useful first request names the outcome and the material. “Summarize the notes in this folder” is enough. “Draft a reply to the client about the 4 June launch” is better than “help me.”

Press Enter to send. A follow-up can be short, because koma still has this conversation in front of it.

:::note[If this is not what you see]
If Enter does nothing, click the terminal window so it has focus, then try again. If the bottom line is not ready, koma is still working. You can wait, or press Esc to stop it.
:::
