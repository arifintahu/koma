# The chat screen

After setup, almost everything happens on one screen. You do not need to learn it all at once. Three parts matter on the first day.

import { Guide } from '../../components/Guide.client'
import { chatSteps } from '../../guides/start'

<Guide steps={chatSteps} />

The conversation is the scrolling area. Your requests and koma’s answers stay there.

The line above the box tells you the koma version, how careful it is right now, and which model will answer.

The box is where you type. The name on its corner is the name of this conversation. The bottom line says ready when koma is waiting, and a working word when it is busy.

A tip rotates under that. You can ignore the tips until you want a shortcut.

:::note[If this is not what you see]
If the screen is only a short message about the window size, widen the terminal. The chat comes back on its own.
:::
